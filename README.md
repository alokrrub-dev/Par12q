# Telegram Gifts market tracker

Полный асинхронный бот находится в `telegram_gifts_bot/`. Запуск из корня репозитория:

```bash
python -m venv .venv
.venv\\Scripts\\activate       # Windows
pip install -r requirements.txt
copy .env.example .env
python telegram_gifts_bot/main.py
```

На Render используется Native Python и `Procfile` из корня. Все данные доступа, фильтры и
история обработанных лотов хранятся в Neon PostgreSQL. `SESSION_STRING` должен быть сессией
обычного пользовательского аккаунта, а не бота; SMS/интерактивная авторизация намеренно
отключены.

Обычный Pyrogram 2.0 не содержит актуальных Gifts/paid-messages конструкций. Поэтому
`requirements.txt` устанавливает совместимый форк Kurigram, который импортируется тем же
пространством имён `pyrogram` и поддерживает актуальный MTProto слой.

## Что делает сканер

`payments.getResaleStarGifts` опрашивается для каждой категории с интервалом `POLL_INTERVAL`
(1–3 с). Продавец проходит проверку только когда Telegram возвращает `stars_rating.level` 0
или 1 и обе величины `send_paid_messages_stars` равны нулю. В памяти хранится кольцевой буфер
2000 ID, а таблица `processed_gifts` атомарно резервирует каждый ID до отправки уведомления.

Алерты также дедуплицируются по Telegram ID владельца: один человек — один алерт,
даже если у него несколько подарков в разных категориях. Таблица `alerted_owners`
автоматически создаётся при запуске и сохраняет историю после перезапуска. Повторные
подарки владельца отмечаются как `duplicate_owner`. Резервирование выполняется до
отправки, поэтому при неоднозначном сетевом сбое бот не повторяет попытку отправки.
История владельцев начинается с установки этого обновления: предыдущие записи
`processed_gifts` не содержали ID владельца, и восстановить его из них невозможно.

В меню активного пользователя доступны «Каталог подарков», «Начать парсинг», «Остановить» и
«Выбранные подарки». В каталоге можно выбрать отдельные категории, выбрать все или снять весь
выбор. Каталог выбора показывается постранично по 20 категорий, чтобы не превышать лимиты
Telegram inline-клавиатуры. Если снять весь выбор, категории не мониторятся.

`/health` и `/ready` возвращают `200 OK`; `PORT` берётся из окружения (по умолчанию 8080).
